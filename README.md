# 💎 MetalMarket - 글로벌 귀금속 및 원자재 실시간 시세 대시보드

MetalMarket은 금(Gold), 은(Silver), 구리(Copper), 플래티넘(Platinum) 등 주요 금속의 실시간 시세와 기간별 시세 변동 추이를 직관적으로 모니터링할 수 있는 **단일 페이지(SPA) 웹 애플리케이션**입니다.

---

## 🌟 주요 기능
1. **실시간 금속 시세 카드뷰 (Top Card Grid)**:
   - 금(XAU), 은(XAG), 구리(XCU), 플래티넘(XPT) 4종 실시간 가격 및 전일 대비 변동률(%)
   - 미니 스파크라인(Sparkline) 차트 및 당일 최저/최고가 게이지 바
2. **세로형 독립 시세 변동 그래프 (Vertical Stack Charts)**:
   - 각 금속별로 왜곡 없는 개별 캔버스 차트를 세로로 1개씩 독립 배치
   - 기간 필터 제공: `5일 (5D)`, `1주일 (1W)`, `1개월 (1M)`, `3개월 (3M)`, `1년 (1Y)`
3. **통화 및 단위 환산**:
   - 통화: `USD ($)` ↔ `KRW (₩)` 실시간 환율 반영
   - 중량 단위: `온스(oz)` ↔ `그램(g)` ↔ `돈(3.75g)`
4. **실시간 금속 가치 계산기**:
   - 보유한 금속의 종류와 중량을 입력하면 현재 시세 기준으로 즉시 환산
5. **다크 글래스모피즘 핀테크 디자인**:
   - 반응형 모바일/태블릿/데스크톱 완벽 대응 및 미려한 마이크로 인터랙션

## 🚀 GitHub Pages 배포 방법 (초간단 3단계)

이 프로젝트는 별도의 빌드 과정(Node.js, Webpack, Vite 등)이 필요 없는 **순수 정적 웹 애플리케이션(Static Web App)**이므로, 깃허브에 올리고 버튼 몇 번만 누르면 즉시 웹사이트로 서비스됩니다.

1. 본 프로젝트의 파일들을 깃허브 저장소(Repository)의 `main` 브랜치에 푸시(Push)합니다.
2. 깃허브 저장소 상단 메뉴의 **Settings** 탭 클릭 ➔ 좌측 사이드바에서 **Pages** 클릭.
3. **Build and deployment** 항목의 Source를 `Deploy from a branch`로 선택하고, Branch를 `main` (또는 master) / `/ (root)`로 지정한 뒤 **Save**를 누릅니다.
4. 약 1분 후 `https://<사용자이름>.github.io/<저장소이름>/` 형태의 전용 라이브 URL이 생성됩니다.

## 📁 파일 구성
- `index.html`: 메인 마크업
- `style.css`: 다크 글래스모피즘 디자인 시스템
- `api.js`: MetalpriceAPI 통신 및 스마트 폴백 엔진
- `charts.js`: Chart.js 기반 독립 차트 렌더러
- `app.js`: 애플리케이션 상태 제어 및 인터랙션 로직
- `server.js`: 로컬 개발용 경량 웹 서버 (`node server.js`)
